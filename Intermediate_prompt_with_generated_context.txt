B. monthly_simulator.py

Create or preserve the main function:

run_intermediate_monthly_simulator()

This function should orchestrate the full Intermediate workflow:

1. Load inventory.
2. Generate or load monthly transactions.
3. Join transactions with inventory using product_id.
4. Compute transaction-level values:
   - revenue = quantity_sold * unit_price
   - expense = quantity_sold * unit_cost
   - gross_profit = revenue - expense
5. Compute product-level monthly summary:
   - product_id
   - product_name
   - category
   - starting_stock
   - total_quantity_sold
   - unit_cost
   - unit_price
   - total_revenue
   - total_expense
   - gross_profit
   - remaining_stock
6. Compute ledger summary:
   - total_revenue
   - total_expense
   - gross_profit
   - total_quantity_sold
   - number_of_transactions
   - number_of_products_sold
7. Generate restock recommendations.
8. Generate dashboard-ready data.
9. Save all CSV outputs.
10. Save all SQLite outputs.
11. Return a dictionary of DataFrames.

average_daily_sales = total_quantity_sold / number_of_days
